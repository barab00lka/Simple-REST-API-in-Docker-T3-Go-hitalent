# Запуск проекта:

``` ./run.sh ``` соберет бинарь сервера на Go в докере, затем поднимет легковесный production контейнер с сервером, а так же контейнер с БД Postgres. 

***Порт сервера 80 в контейнере имеет маппинг на порт 8080 хоста***

``` ./run.sh --with tests ```  соберет бинарь сервера на Go в докере, затем поднимет контейнер с сервером и тестами, а так же контейнер с БД Postgres. Затем запустит тесты в контейнере через Docker

# Структура проекта: 
``` 
.
├── docker-compose.yml
├── Dockerfile
├── README.md
├── run.sh -> скрипт для запуска проекта
├── src -> исходный код и миграции для ДБ
│   ├── go.mod
│   ├── go.sum
│   ├── internal
│   │   ├── crud -> взаимодействие с БД
│   │   ├── models -> модели БД для gorm
│   │   └── service -> бизнес-логика
│   ├── main.go
│   └── migrations -> миграции БД

```
