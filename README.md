## Инструкции по сборке и запуску:

#### Запуск Production сборки:
*соберет бинарь сервера на Go в докере, затем поднимет легковесный production контейнер с сервером, а так же контейнер с БД Postgres и схемой требуемой по заданию.*

    ./run.sh 

#### Сборка с автоматическим запуском тестов:
*поднимет БД, контейнер с сервером и тестами миграций через goose и тест эндпоинта через net/http/httptest. Затем запустит тесты в контейнере*

    ./run.sh --with-tests  

***Порт сервера 80 в контейнере будет иметь маппинг на порт 8080 хоста***
